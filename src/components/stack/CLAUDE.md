# stack/
> L2 | 父级: /CLAUDE.md

/stack 页面的卡带。每个工具是一盘红白机样式的游戏卡带，同一分类的卡带叠成一摞，画在一块 WebGL 画布上。
数据在 `src/data/tools.json`（每个工具带 `shell` 外壳色和 `label` 贴纸路径），贴纸图在 `public/stack/labels/`。

## 成员清单
cartridge-rack.js: 客户端组件，一个分类的区块。左边工具清单，右边一摞卡带；持有选中项、悬停项和键盘焦点项；每盘卡带配一个只给键盘和读屏用的隐藏按钮，处理回车、方向键与 Esc。
cartridge-pile.js: 客户端组件，React 与三维场景之间唯一的接缝。给一摞卡带占位，放画布和接指针的命中区，动态加载 cartridge-scene.js；浏览器不支持 WebGL 时不渲染画布。
cartridge-scene.js: three 场景，不认识 React。一个分类一块画布：相机、灯光、阴影、指针命中、弹簧驱动的逐帧循环；只在有东西在动时渲染。
cartridge-model.js: 卡带的网格与材质。外壳由截面轮廓放样而成，一盘卡带三个网格：外壳、贴纸、顶面的工具名。几何体和颗粒贴图全场景共用一份，每盘只有颜色和贴图不同。
cartridge-loft.js: 放样工具，只懂几何，不认识卡带。把一串截面轮廓连成曲面、封盖、挖孔，按夹角自动区分硬边与圆滑面。
cartridge-pose.js: 姿态与运动规则，纯函数，不依赖 three 和 DOM。尺寸常量、叠放/悬停/选中/进场四种姿态、弹簧。
cartridge-pose.test.js: 姿态规则与弹簧的测试：让位方向、悬停不换位、最长帧步长下一秒内停稳且过冲不超过 5%、中途换目标不丢速度。
cartridge-loft.test.js: 放样约定的测试：曲面封闭、法线朝外（带符号体积等于实体体积）、递减 z 挖孔、同一深度两圈成壁。

## 约定
清单是信息本体，卡带是它的实物索引。工具的链接和说明只出现在清单里。tools.json 里的 `tip` 字段目前不显示。
依赖方向单向：rack → pile → scene → model → loft；pose 被 pile 和 scene 引用。three 只出现在 scene、model、loft 三个文件里，随 `import('./cartridge-scene')` 按需加载，不进其他页面的包。
场景里 1 个世界单位等于 1 个 CSS 像素。卡带尺寸只在 cartridge-pose.js 的 `CARTRIDGE` 定义，画布占位和三维模型读同一组数。
卡带本地坐标：+y 是顶面，+z 是贴纸面。pitch 为 0 时贴纸正对读者，正值时顶面转向读者。叠放时顶面朝前，工具名印在顶面上；贴纸朝下前方，下半截被下面一盘挡住。
外壳形状参考 mamuso.dev 的红白机卡带（上宽下窄、底部金手指舌头、三面凸起的边框、顶面两个卡口、侧面防滑纹、前后壳合缝）。该仓库没有许可证：只取形状和参数，几何体由本目录代码生成，不引用它的模型文件和代码。
贴纸槽是外壳正面真实挖出的凹槽，宽高比 3:2，与贴纸图一致，贴纸不裁切。
运动全部由弹簧驱动，速度留在弹簧里：指针在卡带之间快速移动时目标随时改变，运动不会断开重来。位移弹簧比转动弹簧硬，让位先完成，立起来的卡带不扫到邻居。
画布比一摞卡带大一圈（卡带立起来、投下阴影时不被裁掉），自身不接指针；指针事件由 cartridge-pile.js 的命中区接收。
新增工具：在 tools.json 加一条，放一张 480×320 的 WebP 到 `public/stack/labels/<slug>.webp`。贴纸画风见 `public/CLAUDE.md`。
